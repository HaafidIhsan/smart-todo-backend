# Smart To-Do List Application

An AI-powered task management web application built with FastAPI, Scikit-learn, and JavaScript.

## Features
- Task Management (Add/View tasks)
- ML Priority Prediction using Scikit-learn model
- Async Fetch API Frontend

## Tech Stack
- **Backend:** FastAPI (Python)
- **Machine Learning:** Scikit-learn (`priority_model.pkl`)
- **Frontend:** HTML, CSS, JavaScript
